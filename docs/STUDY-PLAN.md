# Study plans — CT-SEC

Two schedules. Pick by how much time you have, not by how confident you feel.

Both are ordered **by points per hour, with the process core early** — not by chapter number. The
syllabus is long (**1,110 teaching minutes, about 18.5 hours** before any practice) and its biggest
time sink, Chapter 5, returns the least. Chapter 4 is one-fifth of the paper and **must never be the
thing you run out of time for**.

**The single planning fact that matters:** the pass mark is **52 of 80**, and the 20 K2 questions
are only **20 points**. You pass on the **K3 and K4 scenarios** — so every week includes Section 4
scenario practice, not just reading.

## What “covered” means

A chapter is covered when you can, without notes:

- **Chapter 1** — state why test results (not reviews) prove policy effectiveness; list the five
  asset questions; name the three external stakeholders; read the risk matrix; name the five audit
  pillars.
- **Chapter 2** — map all six stakeholders to benefits; state the scope rule both ways; filter
  security from functional objectives; place IA relative to testing; recite the policy hierarchy.
- **Chapter 3** — name the step for any activity; list the six plan elements; write the six-step
  lockout procedure; give the three environment attributes; run the four-step vulnerability response.
- **Chapter 4** — give the four lifecycle reasons; run the six-heading requirements checklist and
  the IEEE ten; classify any coverage measure; produce an EP minimum, a condition list and an
  acceptance-criteria set for a stated requirement.
- **Chapter 5** — for each of the eight mechanisms, state the concept, the weakness and the test.
- **Chapter 6** — separate passive from active reconnaissance; give insider vs external motives;
  recite the three forensic phases and five steps; list nine social engineering techniques; give the
  six case-study questions.
- **Chapter 7** — list the eight report sections; say where risk goes; state the need-to-know rule.
- **Chapter 8** — explain why dynamic security tools probe the system; list the open source ROI
  aspects and the vendor attributes.
- **Chapter 9** — list the four benefits; contrast regulatory and contractual use; classify shall,
  should and may.

## Daily habits that matter more than the schedule

1. **Explain one Section 2 concept card aloud every day**, even on rest days. Ten minutes. Cover
   the card, explain it in your own words with an example, then check. If you cannot give the
   example, you do not understand it yet.
2. **One scenario question on paper per session.** Write the reasoning, not just the letter.
3. **Rebuild one table from blank paper each session.** Recognition is not recall.
4. **Keep a one-page error list.** Every miss in one line: the objective, the trap, the correct
   rule. By the last week this page is your entire revision.
5. **Read the official syllabus alongside Section 1.** The guides quote it heavily, but the exam is
   written from the source document, and its phrasing is what appears in the options.
